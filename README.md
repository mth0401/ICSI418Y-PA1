Application: Task Master

Usage: This application can manage your tasks. Individual tasks can be added and once added, can be completed. Individual tasks can also be deleted if a mistake is made. Any task can be used. Different priorities change the color of the tasks. Tasks are shown on the screen.

Instructions: Type the task into the text box, select a priority with the dropdown menu, then press "Add Tasks" button. To display tasks, press "Display Tasks" button.
